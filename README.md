# Phone Element Inspector

Windows app. Download **PhoneElementInspector.exe** from [Releases](https://github.com/nilbogadmin/PhoneElementInspector/releases/latest) and double-click it.

ADB is inside the exe. Plug in the phones with USB debugging on. The mirror stays open. The dropdown picks which phone you train. ADD names the selected element and creates a click rule. START runs those rules on every connected phone.

Tags and rules are saved in a `data` folder next to the exe.
